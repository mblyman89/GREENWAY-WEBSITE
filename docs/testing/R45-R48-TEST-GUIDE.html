Website Editor Test Guide: R45 to R48

Greenway Marijuana: one place for every test from the website-editor "top-off" rounds (R45, R46, R47 and the R48 polish round). Tick each box as you go and write down anything that doesn't work.

Do these 3 setup steps first (once). Open Supabase, then the SQL editor. Paste and run each file below in order. Until a file is run, the features that need it stay switched off safely; nothing breaks.

If one has already been run, Supabase may say it already exists. That is fine; move on to the next.
Handy tips for testing
  • Staff preview vs customer view. When you are logged in and previewing, the site shows drafts and editing tools. To see what a customer sees, use a private / incognito window where you are not logged in.
  • Phone checks. Use a real phone, or on a computer make the browser window very narrow.
  • After publishing, allow up to a minute, then refresh the public page.

R45: Carousel accessibility, safer uploads, faster pictures, edit protection

R45-1. Carousel pause / play button and swiping (home page and Shop page)

  1. Open the home page on a computer. The top carousel should rotate by itself.
  2. Find the small pause button (before the slides). Click it. Expected: rotation stops and the button changes to play. Click again and it starts.
  3. Hover the mouse over the carousel. Expected: it pauses while you hover.
  4. Press Tab until keyboard focus lands inside the carousel. Expected: rotation stops for good (so keyboard users aren't rushed).
  5. On a phone: Expected: the carousel does not auto-rotate. Swipe left/right to change slides; normal up/down page scrolling still works.
  6. Slides with lots of text should stay up a little longer (6 to 10 seconds).
  7. Repeat steps 1 to 5 on the Shop page (/menu) banner carousel.

R45-2. Upload safety check (Media Library)

  1. Go to Admin, Website, Media Library. Upload a normal PNG or JPEG. Expected: it uploads as always.
  2. Upload a normal MP4 video. Expected: it uploads.
  3. Rename a text file to fake.jpg and try to upload it. Expected: it is refused, because the file's real contents aren't a picture.
  4. (Optional) Try an iPhone .mov (QuickTime). Expected: refused. Convert it to MP4 first.

R45-3. Faster pictures and blurry "loading" previews (needs migration 0266)

  1. Upload a new photo in the Media Library and use it on a home slide or Shop slide. Publish.
  2. In an incognito window, open the page on a slow connection (or a phone on cellular). Expected: a soft blurred version shows for a moment before the sharp picture.
  3. Pictures uploaded before this change have no blur preview. Re-upload one to get it. That is expected.

R45-4. "Someone else saved first" protection

  1. Open Admin, Website, Header & Footer in two browser tabs.
  2. In tab 1, change a piece of wording and save.
  3. In tab 2 (still showing the old version), change the same wording and save.
  4. Expected: tab 2 shows an amber box: "Your change wasn't saved, because someone else saved first", with a Reload latest version button. Tab 1's save is not overwritten.

R46: Scheduling, Releases and SEO

R46-1. Schedule a change to go live or come down (needs migration 0267)

  1. Open Admin, Website, Home, carousel tab. Edit a slide and save the draft (don't publish).
  2. Under that slide find the Schedule strip. Choose "Go live (publish the saved draft)" and a time about 10 minutes from now. Save it.
  3. Wait until the time passes (it runs every 5 minutes, so allow up to 5 extra minutes). Expected: the public home page shows the new version.
  4. Try "Come down (hide it)" on another slide. Expected: after the time, the slide disappears from the public site.
  5. The same Schedule strip is also under Shop banner slides, page sections and FAQ questions. Try at least one.
  6. Open Admin, Website, Schedule & Releases. Expected: "Coming up" lists what's scheduled, and "Last 14 days" lists what already ran.
Go live worked    Come down worked    Schedule page lists both

R46-2. Releases (several changes go live together)

  1. On Schedule & Releases, type a name in New release name and press Create release.
  2. Use Add to release to add two or three items (for example two slides set to "Go live").
  3. Either give the release a time, or press Publish now. Expected: all items go live together, and the release shows as published.
  4. Make another release and press Cancel release. Expected: nothing in it goes live.
Release published together    Cancel works

R46-3. SEO Editor really changes Google results

  1. Open Admin, Website, Website Sync, SEO Editor (or go to /admin/content/seo).
  2. For /about, change the Title and Description and save.
  3. In an incognito window open /about. Right-click, choose View page source, and search for <title>. Expected: your new title. If your title already says "Greenway", the brand isn't added twice.
  4. Tick No-index for one page and save. Expected: its page source contains noindex, follow, and that page disappears from /sitemap.xml. Untick it afterwards!
  5. Try a Canonical pointing at another website. Expected: refused, and nothing saved.
  6. /medical and the three legal pages now appear in the SEO Editor too.

R47-2. Home carousel "Advanced options" (needs migration 0268)

  1. Open Admin, Website, Home, carousel tab. Open a slide and expand Advanced options.
  2. Try each option: font and colour for the eyebrow, title and description lines; hide a line; a separate Phone picture; picture focus (5 positions); text left / center / right and top / middle / bottom; a Start / End show window.
  3. Turn on Custom design (optional) to drag text and buttons anywhere, just like the Shop and Loyalty banners.
  4. Save and Publish. Check the home page on a computer and a phone. Expected: the changes show. Slides that never used Advanced options look exactly as before.
  5. Set an End time in the past on a test slide. Expected: customers don't see it, but your staff preview still does.

R47-3. Category cards: advanced options and video

  1. Open Admin, Website, Home, type cards tab (category cards).
  2. On one card, pick a video (MP4 or WebM) from the Media Library. Expected: the card plays the video on the home page.

R47-4. SEO share picture (what shows when a link is shared)

  1. In the SEO Editor, on any page press Choose picture. Search, pick one, and Save.
  2. A warning appears if the picture is smaller than 600 x 315 (1200 x 630 is best).
  3. Paste that page's full address into the Facebook Sharing Debugger (developers.facebook.com/tools/debug) and press Scrape Again. Expected: your picture shows.
  4. Press Use site default and save. Expected: it goes back to the normal site picture.
Picture shows in debugger    Site default restores

R47-5. Click tracking and Reports, Website Clicks (needs migration 0268)

  1. In an incognito window (not logged in), click a few banner buttons: home slides, Shop banner, Specials hero, Loyalty hero.
  2. Back in admin, open Reports and the Website Clicks tab. Try 7, 30 and 90 days.
  3. Expected: your clicks appear in total clicks, phone / tablet / computer, the daily chart, top slides, top buttons and pages. "Banners nobody pressed" lists live slides with no clicks. The "Page speed" card links to Vercel.
  4. Clicks you make while logged in and previewing are not counted, on purpose. Visitors with "do not track" (GPC) turned on aren't counted either.
Clicks appear in the report

R47-6. Google Store Listing (opening hours for Google)

  1. Open Admin, Website, Google Store Listing (also linked from the SEO Editor).
  2. Change a day's hours. Tick Midnight for one day. Tick Closed all day for another (then put it back).
  3. Try an opening time before 8:00 AM. Expected: a red note about WAC 314-55-147, and Save is blocked.
  4. Press + Add holiday / special hours: for example "Thanksgiving", a date in the future, Closed all day. Save. Expected: "Store hours saved."
  5. Go to search.google.com/test/rich-results, enter https://www.greenwaymarijuana.com/locations and run the test. Expected: a "Local business" result with your weekly hours and the holiday.
  6. Remember: the hours text customers read in the footer and on /locations is separate wording (Header & Footer). Keep it matching, and also update your Google Business Profile in Google.

R48 polish: Move mode for Home slides, code-quality fix

R48-1. Drag text on Home slides in the live preview (Move mode) (needs migration 0268)

  1. Make sure a Home slide has Advanced options, Custom design turned on (R47-2) and is saved.
  2. Open Admin, Website, Website Sync, then the Live preview tab, with the home page (/) showing.
  3. Turn on Move mode: On. Expected: the slide's text boxes and buttons get dashed outlines.
  4. Drag the title somewhere new (or click it, use the arrow keys, then press Enter). Expected: a message says it moved and was saved as a draft, with a link to the Home carousel editor.
  5. Make the preview narrow (phone size) and move it again. Expected: the message says "(phone layout)", and the computer layout isn't changed.
  6. Open the Home carousel editor and Publish the slide. Check the public home page. Expected: the new position is live. Nothing goes live until you publish.
  7. Bonus: on a Shop or Loyalty banner, tick an eyebrow visible (it now shows, see R47-1) and drag it in Move mode. Expected: it moves and saves. Before this round that eyebrow couldn't be dragged.
  8. Classic home slides (no Custom design) have nothing to drag. That is expected.
