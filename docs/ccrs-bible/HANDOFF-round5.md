## 5. What CCRS is, in one page (so you do not have to re-learn it)

**What gets filed**
- Washington's LCB requires every licensee to file weekly CSVs to **CCRS**. Retailers file Strain, Area, Product, Inventory, InventoryAdjustment, InventoryTransfer (receiver only) and Sale.
- Uploads go in **groups**, in this order:
  - Group 1: Strain, Area, Product.
  - Group 2: Inventory.
  - Group 3: adjustments, transfers, sales.
  - The guide asks for a 10-minute wait between groups `[G L0084-L0089]`, `[G L0529-L0530]`.

**File format**
- 3 header rows.
- `NumberRecords` must equal the row count exactly. CCRS calls a mismatch "CheckSum and number of records don't match".
- Exact template column row, CRLF line endings, no BOM.
- Dates are `MM/DD/YYYY`. File stamps are in Pacific time.
- **CCRS's reader splits on every comma**, even inside quotes, so commas, quotes and line breaks are withheld (E42/E43/E38).

**How CCRS answers**
- Success arrives by email from `info@lcb.wa.gov`, subject `PRE: CCRS Processing Successful` (in PREprod), within 30–90 s.
- An error arrives as an email with a **CSV attached**: the file we sent, echoed back with an `ErrorMessage` column.
- **The ErrorMessage text is per-FILE, not per-row.** Never tell the owner "row N is the problem" from that column.
- Parse error files **by column name**, never by position.
- Header and operation errors fail the whole file. Row errors fail only those rows `[EXAM L0532]`.

**Identifiers and history**
- Ids must stay stable. Insert a new id; Update or Delete one CCRS already holds. Getting this wrong produces "Duplicate External Identifier" or "ExternalIdentifier not found".
- That is why the **ledger** exists (S-12a/b, migrations 0247/0248). It was seeded from the LCB's copy of everything Cultivera filed through 2026-09-18: 62,744 lots, 64,563 products, 9,692 strains, 9 areas, 137,008 rows in total.
- Cultivera has been Greenway's integrator. The planned hand-over:
  - Cultivera's last week is Oct 25–31, due Sun 11/01.
  - Greenway's first self-upload is **Sun 11/08**, covering 11/01–11/07.
  - Details are in `docs/audit/CUTOVER-CHECKLIST.md` C-120 … C-150 and in bible Parts 05/07/17.

**Environments and the integrator path**
- Two environments, **PROD** and **PREprod**. They share no data `[FAQ L0096]`. The hub has a PREprod/PROD switch, and a ledger per environment.
- The FAQ says "no API" `[FAQ L0179]`, but an Integrator API Guide (Aug 2026) exists for approved integrators.
- **Greenway applied on 2026-10-19 to be its own integrator (LIQ1455).** See bible Part 18.
